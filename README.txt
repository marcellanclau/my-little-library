MY LITTLE LIBRARY — versão web instalável (PWA)

1. Publique os arquivos desta pasta juntos em um site HTTPS (por exemplo GitHub Pages ou Netlify).
2. No iPhone, abra o endereço publicado no Safari, toque Compartilhar > Adicionar à Tela de Início.
3. O aplicativo funciona offline depois da primeira abertura online.
4. Seus livros são armazenados apenas no navegador/dispositivo. Exporte CSV regularmente; reinstalar/limpar dados pode apagá-los.
5. A prévia de widget dentro da página NÃO é um widget iOS real. Para um widget nativo, é necessário desenvolver e instalar um app iOS com WidgetKit (Xcode/conta Apple).
6. O Kindle não fornece uma API pública para sincronização completa da biblioteca. Use a importação CSV manual.
7. O arquivo HTML local isolado não permite instalar corretamente o PWA; precisa ser servido por HTTPS.
